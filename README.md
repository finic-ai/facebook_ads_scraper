> **This is a legacy boilerplate for Finic's former web automation product, which no longer exists. It is no longer maintained.** Finic now builds AI to stop fraud, abuse and financial crimes: [Finic Grayson](https://docs.finic.ai), a decision model API for real-time fraud and risk decisions, and agents for fraud investigations. See [finic.ai](https://finic.ai).

# finic-boilerplate
Boilerplate for a new finic project.

## Capture a workflow
```bash
finic capture
```

## Run locally
```bash
poetry install
poetry run start
```
